## 📌 Summary

A PowerShell-based monitoring script that continuously tracks file system activity and network timeout events, sending real-time alerts via **ntfy** when thresholds are breached. Designed for operational environments, this script helps proactively detect issues such as file processing delays and server connectivity problems.

It combines folder monitoring and log analysis into a single lightweight solution, making it ideal for IT support, automation, and infrastructure monitoring.

***

### ✨ Features

* 📂 Monitors folder file counts against a configurable threshold
* ⏱️ Detects prolonged low file volume (backlog/stuck process)
* 🌐 Scans logs for recent **network timeouts**
* 🚨 Sends real-time alerts via **ntfy (HTTP notifications)**
* 🔁 Runs continuously with configurable refresh intervals
* 🧠 Tracks duration before alerting to avoid false positives
* 📊 Displays live console status and countdown timer

***

### 🛠️ Tech Stack

* **PowerShell** – Core scripting and automation
* **File System Monitoring** – Folder/file tracking
* **Log Parsing** – Timeout detection from logs
* **HTTP (ntfy)** – Alert delivery

***

### 🎯 Use Case

Built for IT operations and support teams to monitor:

* File queues or batch processing pipelines
* Server/network reliability (timeout detection)
* Background processes that may silently fail
